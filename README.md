# Portfolio

A modern, animated personal portfolio built with Next.js and React. The site highlights experience, projects, education, skills, and contact information in a polished single-page experience.

## Features

- Responsive and visually rich layout
- Smooth animations and interactive UI elements
- Sections for about, experience, projects, skills, education, and contact
- Optimized for modern browsers and deployment on Vercel

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Build

To create a production build:

```bash
npm run build
```

## Project Structure

- src/app - main app router pages and metadata
- src/components - reusable UI sections
- src/lib - portfolio data
